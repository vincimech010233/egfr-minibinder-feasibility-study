# EGFR minibinder feasibility study

[Español](README.es.md)

An independent preparation and feasibility study for a public protein-design challenge track. The work examined public human and mouse EGFR sequence and structure data, documented a proposed design workflow, and assessed whether the local CPU environment could run the selected model.

## Evidence and status

- **VERIFIED:** a local sequence and structure comparison was completed for the selected EGFR domain.
- **OBSERVED:** the one model smoke attempt stopped under a host memory/swap limit and produced no candidate structures.
- **NOT_VERIFIED:** successful model inference, candidate binders, binding, affinity, cross-reactivity, pH selectivity, and novelty.
- No challenge terms were accepted and no submission was made. This project is not affiliated with or endorsed by the challenge organizers.

The repository is a feasibility record, not a protein-design result. Structural similarity and sequence analysis do not establish binding. Experimental validation would be required for biological claims.

## Scope

The study planned to explore de novo minibinders for human EGFR and compare selected regions with mouse EGFR. The proposed pH-selectivity mechanism remains a hypothesis. A local model run was attempted but did not complete; no designed protein is presented.

## Reproducibility

The published work is limited to a concise research record. Large model weights, private environment files, local logs, submission drafts, and challenge materials are excluded. Source data and their provenance should be checked against the cited upstream databases before reuse.
