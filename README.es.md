# Estudio de viabilidad de minibinders para EGFR

[English](README.md)

Estudio independiente de preparación y viabilidad para una convocatoria pública de diseño de proteínas. Se revisaron secuencias y estructuras públicas de EGFR humano y de ratón, se documentó un flujo de trabajo propuesto y se evaluó si el equipo local podía ejecutar el modelo elegido con CPU.

## Evidencia y estado

- **VERIFIED:** se completó una comparación local de secuencia y estructura para el dominio EGFR seleccionado.
- **OBSERVED:** el único intento de prueba del modelo se detuvo por un límite de memoria/swap del equipo y no generó estructuras candidatas.
- **NOT_VERIFIED:** inferencia completada, minibinders candidatos, unión, afinidad, reactividad cruzada, selectividad por pH y novedad.
- No se aceptaron términos de la convocatoria ni se envió una propuesta. Este proyecto no está afiliado ni cuenta con el respaldo de sus organizadores.

Es un registro de viabilidad, no un resultado de diseño de proteínas. La similitud estructural y el análisis de secuencias no demuestran unión. Las afirmaciones biológicas necesitarían validación experimental.

## Alcance

El plan proponía explorar minibinders de novo frente a EGFR humano y comparar regiones seleccionadas con EGFR de ratón. La posible selectividad por pH sigue siendo una hipótesis. El intento de ejecución local no terminó; no se presenta ninguna proteína diseñada.

## Reproducibilidad

El material publicado se limita a un resumen de investigación. Se excluyeron pesos grandes del modelo, archivos privados del entorno, logs locales, borradores de entrega y materiales de la convocatoria. Antes de reutilizar datos, se deben comprobar las fuentes y su procedencia en las bases públicas citadas.
